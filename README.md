# PDF → Excel 변환기

PDF 파일을 엑셀(.xlsx)로 자동 변환하는 웹 애플리케이션입니다.
텍스트, 표, 스캔 이미지 등 다양한 형태의 PDF를 지원합니다.

---

## 주요 기능

### PDF 유형 자동 감지
- **디지털 PDF** — 텍스트 레이어가 포함된 일반 PDF 파일을 직접 파싱합니다.
- **스캔 PDF** — 이미지로만 구성된 PDF는 OCR 엔진(Tesseract)을 통해 텍스트를 추출합니다.
- **혼합 PDF** — 페이지마다 자동으로 유형을 판별하여 처리합니다. 디지털 페이지와 스캔 페이지가 섞여 있어도 정확하게 처리합니다.

### 텍스트 추출
- PDF 내 본문 텍스트를 줄 단위로 추출합니다.
- 표(테이블) 영역에 포함된 텍스트는 중복 추출 없이 표 데이터로만 처리합니다.
- 텍스트 위치 정보(좌표)를 기반으로 원본 레이아웃에 가까운 순서로 정렬합니다.

### 표(테이블) 추출
- PDF 내 모든 표를 자동으로 감지하고 구조화된 데이터로 추출합니다.
- 다중 열·다중 행 표를 정확하게 파싱합니다.
- 셀 병합, 빈 셀, 헤더 행을 처리합니다.

### 다국어 OCR 지원
스캔 PDF 처리 시 아래 언어를 선택할 수 있습니다:
- 한국어 + 영어 (기본값)
- 영어만
- 한국어만
- 일본어 + 영어
- 중국어(간체) + 영어

### 스타일이 적용된 엑셀 출력
- **페이지 구분선** — 각 PDF 페이지의 시작을 진한 색상 헤더로 구분합니다.
- **표 헤더 스타일** — 첫 번째 행은 파란 배경 + 흰 글씨로 강조 처리합니다.
- **교차 행 색상** — 짝수/홀수 행에 배경색을 번갈아 적용해 가독성을 높입니다.
- **테두리** — 모든 표 셀에 얇은 테두리를 적용합니다.
- **열 너비 자동 조정** — 내용 길이에 맞게 열 너비를 자동으로 조정합니다.
- 모든 내용을 **하나의 시트**에 페이지 순서대로 출력합니다.

### 웹 UI
- **드래그앤드롭** 또는 파일 선택 버튼으로 PDF 업로드
- 업로드 전 파일명·용량 미리보기
- 변환 진행 상태 표시 (프로그레스 바 + 단계별 메시지)
- 변환 완료 후 즉시 다운로드
- 최대 **50MB** PDF 파일 지원

## 설치 및 실행

### 사전 요구사항
- Python 3.10+
- Tesseract OCR (`brew install tesseract tesseract-lang`)

### 설치

```bash
git clone https://github.com/ji-sulog/pdf-to-excel.git
cd pdf-to-excel

python3 -m venv venv
source venv/bin/activate

pip install fastapi uvicorn pdfplumber openpyxl python-multipart pillow pytesseract pdf2image
```

### 실행

```bash
source venv/bin/activate
python main.py
```

브라우저에서 http://localhost:8000 접속

---

## 사용 방법

1. 브라우저에서 http://localhost:8000 접속
2. PDF 파일을 드래그앤드롭하거나 클릭하여 선택
3. 스캔 PDF의 경우 OCR 언어 선택 (기본: 한국어 + 영어)
4. **변환하기** 버튼 클릭
5. 변환 완료 후 **엑셀 파일 다운로드** 버튼 클릭
